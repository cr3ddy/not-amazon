# Definition of Done (DoD)

A story is Done only when all are true:
- Acceptance Criteria implemented and verified
- Security checks completed (authz/authn/input validation/secrets/logging review)
- Unit + integration tests added/updated and passing
- Minimal E2E smoke updated if user-critical flow changed
- Lint/typecheck pass
- Operational impact documented (runbook/release notes) when applicable
- Jira updated with artifacts (StoryCapsule, ExecutionPlan, TestPlan, GateReport)
